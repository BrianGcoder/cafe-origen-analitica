# Café Origen: análisis de ventas

Proyecto de práctica que analiza una muestra de 12 ventas de Café Origen. Calcula ventas totales, unidades, ticket promedio, la venta más grande, totales por ciudad y productos destacados.

## Requisitos

- Node.js LTS.

## Cómo ejecutar

Desde la carpeta del proyecto, ejecuta:

```bash
node src/explorar.js
node src/verificar.js
node src/reporte.js
```

`explorar.js` muestra los datos de entrada. `verificar.js` prueba los indicadores y compara las versiones con ciclos y métodos. `reporte.js` imprime los resúmenes para la gerente.

## Preguntas que responde

- ¿Cuánto se vendió y cuántas unidades salieron?
- ¿Cuál fue la venta de mayor valor y cuál es el ticket promedio?
- ¿Cuánto se vendió en cada ciudad?
- ¿Qué productos generaron más unidades y más valor?
- ¿Qué resumen corresponde a un día con ventas o sin ventas?
